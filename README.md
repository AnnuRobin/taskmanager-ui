# Task Management System

A full-stack Task Management application built with Angular and Spring Boot. Users can create, view, update, and delete tasks with different statuses and priorities.

## Tech Stack

- Java 26
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Angular
- TypeScript
- Maven
- GitHub

## Features

- Create, view, update and delete tasks
- Task status and priority management
- Input validation
- Exception handling
- REST API
- Swagger API documentation
- MySQL database integration
- Deployed frontend and backend

## Deployment

- Frontend: Cloudflare Workers
- Backend & Database: Railway
